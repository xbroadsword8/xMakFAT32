---

## 架構現況

```
fat32-core/   — 純邏輯函式庫（23 tests, 0 warnings）
  ├── error.rs   ✅ FormatError + ProgressCallback
  ├── fat.rs     ✅ FAT32 磁碟資料結構 + 輔助函式
  ├── mbr.rs     ✅ MBR 分割表定義 (partition type: 0x0C)
  ├── device.rs  ✅ DeviceIO trait + FileDeviceIO (Linux 測試用)
  ├── scan.rs    ✅ 壞軌掃描器 (支援取消/進度)
  └── format.rs  ✅ 頂層格式化引擎 (13 步驟完整流程)

fat32-gui/    — Win32 GUI（條件編譯，Linux 上顯示錯誤訊息）
  └── main.rs    ✅ 完整 Win32 原生 GUI
```

## 已完成的所有 Phase

### Phase 1 ✅ — 重構 fat.rs / mbr.rs
- MbrPartitionEntry、Mbr 從 fat.rs 移至 mbr.rs
- 分割區類型 0x0B → 0x0C (FAT32 LBA)
- Mbr::new() 優化：僅初始化第一個分割區

### Phase 2 ✅ — I/O 抽象層 (device.rs)
- DeviceIO trait: sector_size, total_sectors, read_sectors, write_sectors, lock, unlock
- FileDeviceIO: std::fs::File 包裝（Linux 測試）
- lock/unlock 預設空操作

### Phase 3 ✅ — 壞軌掃描器 (scan.rs)
- BadBlockScanner<D, P>: 逐 sector 讀取檢測
- 進度回報 (每 128 sectors)、取消檢查、invalid range 處理

### Phase 4 ✅ — 格式化引擎 (format.rs)
- FormatConfig: label, cluster_size, quick_format, bad_block_threshold
- 完整 13 步驟: 驗證→MBR→BootSector→FSInfo→保留區→FAT#1/#2→根目錄→壞軌→FSInfo 更新
- MBR/BootSector/FSInfo signature 驗證測試通過

### Phase 6 ✅ — Windows GUI (main.rs)
- Win32 原生視窗 (500x380, 不可調整大小)
- 裝置列舉 (GetLogicalDriveStringsW → DRIVE_REMOVABLE)
- ComboBox: 裝置選擇、叢集大小 (9 選項)
- Edit: 磁碟區標籤 (上限 11 字元, 自動大寫)
- CheckBox: 快速格式化 (預設勾選)
- ProgressBar + 狀態文字
- 背景執行緒格式化 (WindowsDeviceIO + GuiProgress)
- WM_TIMER 定期更新 UI
- 取消支援 + 關閉時等待執行緒
- 非 Windows 平台顯示錯誤訊息

## 決定事項

1. fat32-core 不引入 windows crate — DeviceIO trait 完全解耦
2. 分割區類型 0x0C (FAT32 LBA)
3. 格式化起始 LBA = 2048 (1MB 對齊)
4. GUI 使用全域 static mut 存控制項 handle (Win32 慣例)
5. 條件編譯: `#[cfg(windows)]` module + stub main for non-Windows
